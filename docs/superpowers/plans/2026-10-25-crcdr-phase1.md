# CRCDR Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `CatholicOS/crcdr` repository and seed it from the Roman Curia research. Each curial body gets a canonical `cr:` identifier, a dated history and an event log. The data is checked by a validator, rendered by a generator, and opened as a pull request.

**Architecture:** The repository follows the layout of its siblings (CESIDR, COECDR):
- `data/`: JSON registry, plus vocabulary files.
- `scripts/`: Python, standard library only, with `unittest` tests next to the scripts.
- `registry/`: Markdown generated by a script.
- `docs/`: documentation.

The research files are kept under `seed/research/`. A one-time seeder turns them into `data/`, using curated mapping files in `seed/`. After seeding, `data/` is the source of truth. The seeder stays in the repository for provenance.

**Tech Stack:** Python 3.10+ (stdlib only), `unittest`, `gh` CLI, git.

## Global Constraints

- **Identifier:** `cr:<latin-slug>-<founding-year>`. ABNF: `cr-key = latin-slug HYPHEN year`, `latin-slug = 1*ALPHA *(HYPHEN 1*ALPHA)`, `year = 4DIGIT`. As a regex: `^cr:[a-z]+(?:-[a-z]+)*-\d{4}$`. The year equals the year of `founded.date`.
- **Long form** `curia-romana:`; the short form is canonical. Keys use Latin, in the nominative. Strip the kind words (*Dicasterium*, *Congregatio*, *Sacra*, *Suprema*, *Pontificium Consilium*, *Secretariatus*, *Commissio*, *Tribunal*, *Officium*, *Praefectura*, *Pontificia Academia*) and the governing *pro*/*de*. Keep *et*. Keep the kind word when nothing distinctive would remain. ASCII-fold (æ→ae, œ→oe, diacritics dropped). Mint from the name in use when minting: the current name for a living body, the last name for one that has ended.
- **Dates:**
  - written `YYYY`, `YYYY-MM` or `YYYY-MM-DD`; a partial date compares as its first day;
  - intervals run `from` inclusive to `to` exclusive, with `to: null` meaning still open;
  - the date an act takes effect governs, and `signed` is recorded separately.
- **Provenance on every dated fact:**
  - `verified` (bool);
  - `source_type` ∈ {`primary`, `official-secondary`, `secondary`, `inferred`};
  - a source;
  - optional `note`;
  - optional `gap` (a documented research gap, which turns an error into a warning).

  Seeding must **never** upgrade `verified` or `source_type`.
- **`kind` values:** `congregation`, `council`, `pontifical-council`, `secretariat`, `commission`, `committee`, `dicastery`, `tribunal`, `office`, `prefecture`, `academy`, `institution`.
- **Regimes, with effective dates:**
  - `pre-1588` (open start);
  - `immensa-1588` 1588-01-22;
  - `sapienti-consilio-1908` 1908-11-03;
  - `cic-1917` 1918-05-19;
  - `reu-1968` 1968-01-01;
  - `pastor-bonus-1989` 1989-03-01;
  - `praedicate-evangelium-2022` 2022-06-05.
- **Event types:**
  - same id: `rename`, `rename-competence`, `kind-change`, `competence-transfer`, `revival`, `attachment`;
  - new id: `foundation`, `merger`, `split`, `re-foundation`;
  - `absorption` keeps the absorbing body and ends the absorbed one;
  - `suppression` ends a body.
- **`clause_status`:** `transcribed` | `not-transcribed` | `silent` (`silent` requires `inferred: true`).
- **Phase 1 exclusions:**
  - the research keys `sixtine-temporal-congregations` and `fabric-st-peter`, and the events that involve only them;
  - any body whose founding year the Task 4 research cannot secure.
- **Attribution:** every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. The PR body ends with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- **Licences:**
  - `LICENSE` = **CC BY-ND 4.0** (data, registry, docs);
  - `LICENSE-CC0` = **CC0 1.0** (covers `data/identifiers.json` only);
  - `scripts/LICENSE` = **Apache 2.0**.
- **No authority fields.** Authority is CMDDR's. Do not carry over the research's `issues_doctrinal_documents`.
- **Repository:** `CatholicOS/crcdr`, public, default branch `main`. Every script is run with `python3 -I` from the repo root.

## Review Focus

1. **Boundary dates.** A lookup on the exact day a rename took effect must return the new name, because `to` is exclusive. Tested in Task 2 (`test_name_at_rename_day`).
2. **Partial and non-ISO dates.** The research has `"medieval"`, `"late 14th c."`, `"1588"`. Only well-formed partial dates may reach `data/`; anything else must be resolved (Task 4) or dropped with a `gap`. Tested in Task 2 (`test_parse_date_rejects_prose`) and Task 6 (`test_seeded_dates_are_iso`).
3. **One research event with several effects.** *Sapienti Consilio* renames some bodies, suppresses others and founds others. A single event type on one record would be wrong. The seeder must split such records into one event per effect. Tested in Task 6 (`test_reorganization_split`).
4. **A section entry that crosses a regime boundary.** It must be cut at the regime's effective date. Tested in Task 6 (`test_sections_cut_at_regime_boundaries`).
5. **ASCII folding of Latin ligatures** (`Pœnitentiaria`, `Cæremonialis`) when minting keys. Tested in Task 5 (`test_fold_ligatures`).

### Task 6: Seeder

**Files:**
- Create: `scripts/seed_from_research.py`, `scripts/test_seed.py`
- Create (output): `data/bodies.json`, `data/events.json`, `seed/seed-report.md`

**Interfaces:**
- Consumes: `seed/research/*.json`, every `seed/*.json`, `crcdr.*`, `validate.validate`.
- Produces: `build(research_bodies: dict, research_events: dict, maps: dict, vocab: dict) -> tuple[dict, dict, list[str]]`, which returns `(bodies_doc, events_doc, report_lines)`. `main()` writes the three outputs. The output shapes are the design's §6.1 and §6.2.

**Transformations:**
- **Excluded and held-out bodies** are dropped. Their ids are removed from event `before`/`after` lists, and an event whose lists become empty is dropped.
- **`founded` / `ended`:**
  - taken from research `erected`/`ended`, or from `founding_years.json`;
  - `founded.event` and `ended.event` point to the seeded event that creates or ends the body;
  - a body that is still alive has `ended: null`.
- **`names[]`:** carried over, with provenance unchanged. A `from` that isn't ISO is replaced by the founding date and marked with `gap`.
- **`kind[]`:** through `kind_map`.
- **`section[]`:** computed from the dated `kind` and `regime_at`:
  - cut at every regime boundary inside the body's lifespan;
  - the value is taken from `seed/section_overrides.json` when an override covers that body and regime. Otherwise it is the regime's section whose `kinds` list contains the body's kind, or `not-listed` when there is none. A `not-listed` entry takes `in_curia` from an override when there is one, and otherwise gets `null` with a `gap` note. The research's free-text `curia_status` is never parsed by code;
  - `source_type: "inferred"`, `verified: false`;
  - `note`: "derived from kind and regime".
- **`part_of[]`:** from `part_of.json`.
- **`note`:** research `notes` + `competence_changes`, joined.
- **Dropped:** `issues_doctrinal_documents`, `line`, `predecessors` and `successors`. The seed report compares the predecessor/successor links derived from events with the research's own links, and lists every mismatch.
- **Events:** expanded through `event_map`, so one research event can become several. Each gets an id `ev<NNN>` in research order, with a letter suffix for each expansion: `ev022a`, `ev022b`.
  - `clause_status`:
    - `transcribed` when the event id is in `clauses.json`;
    - `silent` when it is `inferred` or the research `source_type` is `inferred`;
    - otherwise `not-transcribed`.
  - `mag: null`.
  - The research event id goes in `research_id`.
- **Undated facts:** where a research gap breaks a validator rule, add a `gap` note quoting the research's own gap text. Never invent dates.

- [ ] **Step 1: Write the failing tests:**
  - `test_seed_validates`: `build(...)` on the real seed inputs, then `validate(...)`, gives `errors == []`.
  - `test_seeded_dates_are_iso`: every `from`, `to`, `date` and `founded.date` value is `None` or `parse_date`-valid.
