# CRCDR

The home of the **Common Roman Curia Data Repository**, curated by the Catholic Engineering Task Force of the Catholic Digital Commons Foundation: canonical identifiers (`cr:`) for the bodies of the Roman Curia and the institutions connected with the Holy See, with their dated names, kinds and places in the Curia.

**All IDs are drafts pending committee review.**

See the design document: [docs/superpowers/specs/2026-10-25-crcdr-design.md](docs/superpowers/specs/2026-10-25-crcdr-design.md).
